How to read the audit
Only blank cells directly adjacent to a recorded success were probed. All 28 observed contact-feature pairs were tried using polynomial roots.
Recovered: an exact-contact candidate passes the original collision/friction validator.
Joint / friction / object / self: the candidates with the fewest violations fail only that test. This describes candidates in the tested catalog, not a proof that no other grasp exists.
Mixed: different candidates fail different tests, or the least-violating candidates fail multiple tests.
Unresolved: no finite-feature candidate was found in this catalog. Joint counterfactuals were searched only up to ±200°; valid poses still require ±180°.
The boundary audit considers both bands together. Blank uncolored space was not tested. Contact construction uses exact tangency; the original solver permits 0.05 mm contact tolerance.
